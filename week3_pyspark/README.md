# Week 3 — PySpark Data Processing

Based on the PySpark training sections.

## Tasks

### PySpark Fundamentals (`transform.py`)
- Create and manipulate DataFrames from the cleaned Week 2 output (or raw
  source files directly)
- Implement Spark SQL functions
- Work with different datasources (CSV, JSON)
- Use built-in functions for analysis

### Analysis Tasks (`analysis.py`)
- Load and transform movie data at scale
- Perform complex aggregations
- Create analytical views (`createOrReplaceTempView`)
- Generate statistical summaries

## Run

```
python week3_pyspark/transform.py
python week3_pyspark/analysis.py
```

## Grading focus
- DataFrame operations (10%)
- SQL function implementation (5%)
- Data transformation jobs (5%)
- Performance optimization (5%)
