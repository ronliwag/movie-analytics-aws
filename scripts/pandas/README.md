# Python & Pandas Processing

## Tasks

### Python Implementation (`models.py`, `data_processor.py`)
- `Movie` and `Rating` classes (Python Classes/Objects)
- Data processors using Python Dictionaries
- Date standardization using `datetime`
- Type handling using casting
- Batch processing using `for` loops
- Transformations using `lambda`
- Handle the nested JSON structures in `ratings.json`
- Proper file handling (context managers, error handling)

### Pandas Operations (`clean_data.py`, `analysis.py`)
- Load and work with Pandas DataFrames
- Read/process the CSV and JSON source files
- Analyze DataFrames with built-in functions (`describe`, `groupby`, etc.)
- Remove duplicates
- Fix data quality issues (mixed date formats, missing budgets)

## Run

```
python -m scripts.pandas.clean_data
```
